# Asset licensing

The Wrist Remote application icon is original, purely geometric artwork generated deterministically by `scripts/generate-icons.swift`. It uses no external images, fonts, logos, or model-generated assets. The generator, its PNG outputs, and asset-catalog metadata are distributed under GPL-3.0-only with the source code.

Run `make icons` from the repository root to reproduce every committed icon size.

Apple platform-generated masks, layout behavior, and system symbols are supplied by Apple SDKs and are subject to the applicable Apple terms. No user photos, device screenshots, private recordings, or personal artwork are included.
