# 腕上控制中心

打开 Mac 上的 WristRemoteBridge，并让 iPhone 的 Wrist Remote 完成原有配对。手表首页是控制中心：左上角选择设备，底部选择模式，“更多”保留自定义遥控和 Codex。首次授权仍由系统界面完成。

## 电脑控制

| 模式 | 操作 |
|---|---|
| 触控板 | 滑动移动指针，轻点左键，下方按钮右键，转动表冠滚动 |
| 媒体 | 播放/暂停、上一首、下一首、静音，表冠调音量 |
| 演示 | 前后翻页、开始 Keynote、退出演示；作用于 Mac 当前前台应用 |
| 更多 → 自定义遥控 | 继续使用原有 12 键、36 个手势映射和应用快捷动作 |

Mac 控制需要辅助功能权限。操作有时效和重复保护；网络中断或结果不明时不会自动重放。切换目标后，旧目标的迟到回执不会显示成新目标的成功结果。电视与提词模式要求选择对应类型的目标。

## 声音模式

语音都经由 Watch → iPhone → Mac。触控板能直连 Mac，并不表示语音中继也可用。验收声音时，保持手机端打开、手表亮屏；等待“正在录音”与开始震动，再开始说话。

| 模式 | 去向 | 所需条件 |
|---|---|---|
| 语音输入 | 转文字，输入 Mac 当前文本框 | 手表麦克风、Mac 语音识别和辅助功能权限 |
| 保存录音 | Mac 本地 M4A 文件 | 手表麦克风和可用私有中继，不需要 Speech 转写 |
| 无线麦 | Mac 选定的虚拟音频设备 | 手表麦克风、可用私有中继、已选择虚拟输出 |
| Codex 听写 | 手表音频送入 Codex 的原生听写 | 独立虚拟输入输出设备、相同的点按听写快捷键、Codex 前台 |

保存录音使用单声道 AAC，16 kHz、16 kbps，边接收边编码，不保存 WAV。每分钟约 150 KB。点停止后等待 Mac 的成功回执；仅仅按钮恢复成“开始”不表示文件已经保存。在 Mac 的“语音与录音”页点击“打开录音文件夹”检查结果。

保存录音和无线麦每段最多 115 秒。当前前台模式在手表页面失活、连接中断、音频积压或设备变化时停止。被取消的未完成录音会被清理；不会断线续录，也不会重连后自动开始。息屏持续运行尚未交付。

无线麦在 Mac“语音与录音”页选择虚拟音频输出，在会议或录制软件里把同一个设备选为输入。这个设置只改变 WristRemoteBridge 的输出，不改变系统默认输入输出。为防止与现有音频链路冲突，BlackHole 2ch 不在可选列表中；即使以前选过，Mac 也会拒绝向它输出。没有其他虚拟音频设备时，无线麦不可用。是否实际收到声音和延迟大小，需要在目标软件中单独验收；能选择设备不等于整条链路已通过。

### Codex 原生听写（未完成）

此功能尚未完成，当前版本不可启动。现有的 Codex 任务语音功能不受影响。

## 电视

本版提供 Android / Google TV 的固定按键适配。在 Mac“电视”页填写设备名称、实际局域网地址与端口，并选择本机 `adb` 可执行文件。电视需允许对应的调试连接，并由用户在电视确认授权。连接成功后，在手表左上角选电视，再选“电视”模式。

支持方向、确认、返回、主页、播放/暂停和音量。仅发送白名单按键，不接受手表传入任意 shell 命令。连接失败时不会显示一个可用电视。Apple TV 专用适配尚未实现。

## iPad / iPhone 提词与阅读

在阅读设备上打开 Wrist Remote，先与同一 Mac 配对，再进入“提词与阅读”。粘贴内容或导入 UTF-8 文本，空行分段，然后开始会话。手表选择这个会话，即可前后切段、播放/暂停和调节推进速度。阅读设备支持横屏与镜像显示。

正文最大 200 KB、最多 1000 段；标题最多 80 字。页面进入后台或连接中断时结束会话。这里控制的是本 App 的阅读会话，没有实现任意 iPad App 或系统界面遥控。

## 状态和故障

- “语音链路未就绪”：先打开 iPhone 端，检查 Mac 显示 iPhone 已连接；下滑录音页可查看具体提示。
- “正在准备录音”：尚未开始采音；等待开始震动。
- “正在传送尾音 / 等待 Mac 确认”：保持前台并等待结果，避免重复发起录音。
- “操作未完成”：进入“更多”查看失败详情。未确认的控制指令不会自动重发。
- Mac 未发现虚拟设备：点击“刷新设备”。未选输出时无线麦拒绝启动。Mac 拒绝开始时，手表只显示中断提示，具体原因在 Mac“语音与录音”页。
- 手表直连失败：Mac 系统日志的 `watch-direct` 与 `server` 类别记录请求是否到达及拒绝类别（不含内容与密钥），可用于区分网络不通与身份或配对问题。

模拟器验证覆盖界面、消息和异常状态；实体声音、系统权限、触觉、后台行为以及外部设备的实际效果须分别验收。
